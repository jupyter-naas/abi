# `cash_flow.py`

## What it is

- Standalone script (stdlib only) that generates a **fake Cash Flow** dataset for the Financial Cockpit demo.
- Reads each entity’s balance sheet (`web/data/entities/<entity>/balance_sheet/balance_sheet.json`), derives an **indirect-method** cash flow statement per period, and writes:
  - `web/data/entities/<entity>/cash_flow/cash_flow.json`
  - Updates `web/data/entities/<entity>/manifest.json` to include the cash-flow page dataset.
- Ensures reconciliation per period:
  - `opening cash + operating + investing + financing == closing cash`
- Synthesizes a monthly income statement (revenue → gross profit → EBITDA → net income) and publishes it as **memo** lines for other pages (e.g., ratios). Memo lines are not part of the operating/investing/financing totals.

## Public API

This module is designed as a script; only `main()` is intended as an entry point.

- `main() -> None`
  - Discovers entities that have a balance sheet dataset.
  - Generates and writes cash flow datasets and patches manifests.

Internal helpers (not intended as public API):

- `_entities_with_balance_sheet() -> list[str]`: finds entities with a balance sheet file.
- `_load_balance_sheet(entity_id: str) -> dict | None`: loads the entity balance sheet JSON.
- `_build_records(entity_id: str, payload: dict) -> list[dict]`: derives cash flow + memo records from balance sheet snapshots.
- `_scenarios(payload: dict, records: list[dict]) -> list[dict[str, str]]`: reuses or rebuilds scenario options.
- `_patch_manifest(entity_id: str, data_version: str) -> None`: adds the cash-flow dataset to the entity manifest.

## Configuration/Dependencies

- **Input required**: Balance sheet JSON generated by `scripts/performance/balance_sheet.py`.
- **Filesystem layout** (relative to the app root inferred from the script location):
  - Input: `web/data/entities/<entity_id>/balance_sheet/balance_sheet.json`
  - Output: `web/data/entities/<entity_id>/cash_flow/cash_flow.json`
  - Manifest patched: `web/data/entities/<entity_id>/manifest.json`
- **Determinism**:
  - Randomness is seeded per entity (`md5("cf-<entity_id>")`) so re-runs are stable for the same input.
- **Key parameters (constants)**:
  - `DEPRECIATION_RATE = 0.008` (monthly, on opening non-current assets)
  - `INTEREST_RATE = 0.0035` (monthly, on opening borrowings)
  - `TAX_RATE = 0.25` (on positive pre-tax)
  - `OPENING_CASH_FACTOR = 0.985` (used only for first period opening cash)
  - `DIVIDEND_PAYOUT = 0.25` (paid in June from trailing 12-month net income)

## Usage

Run from the Financial Cockpit app root (after generating the balance sheet):

```python
import subprocess

subprocess.check_call(["python", "scripts/performance/cash_flow.py"])
```

Or directly in a shell:

```bash
python scripts/performance/cash_flow.py
```

## Caveats

- Requires existing balance sheet datasets; otherwise exits with:
  - `No balance sheet found — run scripts/performance/balance_sheet.py first.`
- The cash flow is **synthetic** and derived from balance sheet deltas; operating cash flow is computed as a residual and uses `"Other operating items"` as a plug to reconcile exactly.
- Memo lines (`activity: "memo"`) include opening/closing cash and synthesized P&L metrics; they are written into the same dataset but are not part of the three activity sections.
