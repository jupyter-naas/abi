# Gpt4o20240513Model

## What it is
- A model definition that registers OpenRouter’s `openai/gpt-4o-2024-05-13` as a `ChatModel` using `langchain_openai.ChatOpenAI`.
- Exposes a preconfigured, ready-to-use `ChatModel` instance (`model`) with fixed defaults (temperature, timeout, retries) and OpenRouter base URL.

## Public API
- `class Gpt4o20240513Model(ModelDefinition)`
  - Constants:
    - `CANONICAL_ID`: `CanonicalModelId.GPT_4O_2024_05_13`
    - `MODEL_ID`: `"openai/gpt-4o-2024-05-13"`
    - `PROVIDER`: `ModelProvider.OPENROUTER`
  - Attribute:
    - `model: ChatModel`: Configured `ChatModel` wrapping a `ChatOpenAI` client.
- Module-level:
  - `OPENROUTER_BASE_URL = "https://openrouter.ai/api/v1"`
  - `model: ChatModel`: Alias to `Gpt4o20240513Model.model`

## Configuration/Dependencies
- Dependencies:
  - `langchain_openai.ChatOpenAI`
  - `pydantic.SecretStr`
  - `naas_abi_marketplace.ai.openrouter.ABIModule` (used to read configuration)
  - `naas_abi_core.models.Model` types (`ChatModel`, `ModelDefinition`, etc.)
- Required configuration:
  - `ABIModule.get_instance().configuration.openrouter_api_key` must be set (used as the OpenRouter API key).
- Client defaults baked into the definition:
  - `temperature=0`
  - `timeout=120`
  - `max_retries=3`
  - `base_url="https://openrouter.ai/api/v1"`

## Usage
```python
from naas_abi_marketplace.ai.openrouter.models.openai.gpt_4o_2024_05_13 import model

# Access underlying LangChain chat client:
llm = model.model  # ChatOpenAI instance

# Example invocation (requires ABIModule configuration to be set up in your environment/app):
result = llm.invoke("Say hello in one sentence.")
print(result)
```

## Caveats
- API key is fetched at import time from `ABIModule.get_instance().configuration.openrouter_api_key`; missing/misconfigured values can cause import-time failures.
- The exported `model` is a `ChatModel` wrapper; the underlying LangChain client is available as `model.model`.
