# Gpt4o20240806Model

## What it is
- A model definition that registers the **OpenRouter**-hosted **OpenAI GPT‑4o (2024‑08‑06)** chat model as a `ChatModel` using `langchain_openai.ChatOpenAI`.
- Exposes a ready-to-use `model` instance configured with OpenRouter base URL, API key, timeouts, and metadata (context window, pricing, supported parameters, etc.).

## Public API
- `class Gpt4o20240806Model(ModelDefinition)`
  - `CANONICAL_ID`: `CanonicalModelId.GPT_4O_2024_08_06`
  - `MODEL_ID`: `"openai/gpt-4o-2024-08-06"`
  - `PROVIDER`: `ModelProvider.OPENROUTER`
  - `model: ChatModel`: Preconfigured `ChatModel` instance (wraps `ChatOpenAI`) with:
    - `temperature=0`, `timeout=120`, `max_retries=3`
    - `base_url="https://openrouter.ai/api/v1"`
    - `api_key` pulled from `ABIModule.get_instance().configuration.openrouter_api_key`
    - `context_window=128000`
- Module-level:
  - `model: ChatModel = Gpt4o20240806Model.model`

## Configuration/Dependencies
- Dependencies:
  - `langchain_openai.ChatOpenAI`
  - `naas_abi_core.models.Model` (`ChatModel`, `ModelDefinition`, `CanonicalModelId`, `ModelProvider`)
  - `naas_abi_marketplace.ai.openrouter.ABIModule` for configuration access
  - `pydantic.SecretStr` for API key handling
- Configuration required:
  - `ABIModule.get_instance().configuration.openrouter_api_key` must be set (OpenRouter API key).
- Network:
  - Uses OpenRouter endpoint: `https://openrouter.ai/api/v1`

## Usage
```python
from naas_abi_marketplace.ai.openrouter.models.openai.gpt_4o_2024_08_06 import model

# `model.model` is the underlying LangChain ChatOpenAI instance.
llm = model.model

# Example call style depends on your LangChain version and message types.
# This shows a minimal direct call with a plain prompt (may require adaptation).
result = llm.invoke("Say hello in one sentence.")
print(result)
```

## Caveats
- Requires a valid OpenRouter API key accessible via `ABIModule` configuration.
- The snippet uses `invoke`; exact calling conventions can vary by LangChain version and may require proper message objects.
