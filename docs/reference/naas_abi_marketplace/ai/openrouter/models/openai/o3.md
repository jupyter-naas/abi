# O3Model (openai/o3)

## What it is
- Defines the **OpenAI o3** chat model metadata and a preconfigured `langchain_openai.ChatOpenAI` client for use via **OpenRouter**.
- Exposes a ready-to-use `ChatModel` instance (`model`) with provider/model identifiers, context window, pricing/architecture metadata, and client settings.

## Public API
- `class O3Model(ModelDefinition)`
  - `CANONICAL_ID`: `CanonicalModelId.O3`
  - `MODEL_ID`: `"openai/o3"`
  - `PROVIDER`: `ModelProvider.OPENROUTER`
  - `model: ChatModel`
    - A `ChatModel` containing:
      - `model_id`, `provider`
      - `model`: `ChatOpenAI(...)` configured for OpenRouter
      - metadata: `context_window`, `name`, `owner`, `description`, `canonical_slug`, `created_at`, `pricing`, `architecture`, `top_provider`, `supported_parameters`, etc.
- `model: ChatModel`
  - Module-level alias to `O3Model.model` for convenient import/use.

## Configuration/Dependencies
- **Dependencies**
  - `langchain_openai.ChatOpenAI`
  - `pydantic.SecretStr`
  - `naas_abi_core.models.Model` (`ChatModel`, `ModelDefinition`, `ModelProvider`, `CanonicalModelId`)
  - `naas_abi_marketplace.ai.openrouter.ABIModule`
- **Configuration**
  - Uses OpenRouter base URL:
    - `OPENROUTER_BASE_URL = "https://openrouter.ai/api/v1"`
  - Reads API key from:
    - `ABIModule.get_instance().configuration.openrouter_api_key`
- **Client settings (ChatOpenAI)**
  - `model="openai/o3"`
  - `temperature=0`
  - `timeout=120`
  - `max_retries=3`
  - `base_url=OPENROUTER_BASE_URL`

## Usage
```python
from naas_abi_marketplace.ai.openrouter.models.openai.o3 import model

# LangChain chat model client (ChatOpenAI)
llm = model.model

# Example invocation (requires ABIModule configured with openrouter_api_key)
response = llm.invoke("Write a one-sentence summary of the o3 model.")
print(response)
```

## Caveats
- Requires `ABIModule` to be initialized/configured with a valid `openrouter_api_key`; otherwise client construction/auth will fail at runtime.
- This module only defines configuration/metadata; it does not implement custom request logic beyond `ChatOpenAI` configuration.
