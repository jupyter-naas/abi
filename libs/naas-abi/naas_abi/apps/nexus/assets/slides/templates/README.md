# Slides templates

Canonical seed decks for Nexus Slides (`/slides`).

| File | Source |
|---|---|
| `bob-fmz-v1.html` | Jeremy Ravenel BOB / Forvis Mazars slide template (`BOB_Slides_FMZ_Template.html`) |

Each deck is a self-contained HTML file with an in-browser `buildPptx()` export (pptxgenjs). PPTX fidelity is best-effort vs the live HTML preview.

New Slides projects copy this seed into Forgejo at `slides/<slug>/deck.html` on branch `slides/<slug>`.
