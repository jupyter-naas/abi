# Public sources

Do not answer a time-sensitive question from memory.

Use `web_search` when that tool is on the current agent. On the Search agent, use `search_public_web` (Wikipedia or DuckDuckGo), the same public lookup the Search page runs. Private ontology terms use `search_ontology_terms`, and only when the question is about the workspace graph.

Cite only URLs the tool returned. Put the source title and URL next to each claim that depends on a result. A handful of queries is enough. If the tool returns nothing, say that you found nothing.
