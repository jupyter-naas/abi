# Web research

Look it up. Do not answer time-sensitive questions from memory.

Use web_search when that tool is on the current agent. On the Search agent, use search_public_web (Wikipedia or DuckDuckGo) for the same public lookup the Search page runs. Private ontology terms use search_ontology_terms, and only when the question is about the workspace graph.

Run search_public_web or web_search and cite only URLs the tool returned.

A handful of queries is enough. Put the source title and URL next to each claim that depends on a result. If the tool returns nothing, say that you found nothing. Do not fabricate a link, a date, or a quotation.
